# Non-linear premium calculator rewrite for MPS Flexi (v2)

The single-page product HTML has been rewritten to replace a linear per-unit-rate calculator with a discrete lookup-based calculator backed by absolute kontribusi values per UP level. PREMI_DATA now stores one integer kontribusi figure for each of 7-10 discrete UP levels per age/plan/masa-bayar combination. A secondary "berdasar kontribusi" reverse mode interpolates backwards from a target payment to an estimated UP. Syariah terminology has been standardized, and a floating WhatsApp button replaces the old sticky banner.

**Watch for:** Tabel Premi buttons expose only 8 of 12 plan/currency/gender combinations present in PREMI_DATA — Plan A IDR (pria, wanita) and Plan A/C USD wanita are inaccessible (confirmed). The calculator UP dropdown offers options that yield "Data tidak tersedia" for certain plan/age combinations (confirmed).

## High-level view

The v1 floating-point noise has been eliminated (all PREMI_DATA values are clean integers) and the Plan A tab text corrected to state that IDR data is available for ages 18-30.

The Tabel Premi tab exposes 8 switchable views via buttons, but PREMI_DATA contains 12 plan/currency/gender combinations. Four are unreachable: Plan A IDR Pria, Plan A IDR Wanita, Plan A USD Wanita, and Plan C USD Wanita. Users browsing the Tabel Premi tab cannot see these subsets, though the calculator's own dropdowns can reach them.

The calculator dropdown presents all 10 UP levels regardless of what exists for the selected plan/age/masaBayar. For Plan A IDR ages 18-25, selections of Rp 1B, 1.5B, or 2B show an error because data only starts at Rp 2.5B. A filtered dropdown would eliminate the dead options.

File size (715 KB total, 349 KB excluding base64 image) and wide-gap interpolation behavior remain unchanged from v1 — both explicitly accepted as trade-offs.

## Tabel Premi coverage gap

PREMI_DATA contains data for all 12 combinations (3 plans x 2 currencies x 2 genders). The Tabel Premi tab has buttons for:

- Berkah IDR Pria/Wanita
- Berkah USD Pria/Wanita
- Cermat IDR Pria/Wanita
- Cermat USD Pria
- Amanah USD Pria

Missing from the UI:

- Amanah IDR Pria (13 ages, 18-30)
- Amanah IDR Wanita (13 ages, 18-30)
- Amanah USD Wanita (19 ages, 18-30 plus 65-70)
- Cermat USD Wanita (37 ages, 0-30 plus 39-70)

## UP dropdown presents unavailable options

The calculator populates the UP dropdown from a static list (`IDR_UP_KEYS` = 10 values from Rp 1B to Rp 50B). Plan A IDR data starts at Rp 2.5B for ages 18-22, and Rp 2B for ages 23+. When a user selects an unavailable level:

```javascript
var kontribusi=masaData[upVal];
if(kontribusi===undefined){
  resultDiv.innerHTML='<p style="color:#e53935">Data tidak tersedia untuk '+termUP+' ini</p>';
  return;
}
```

The error message is clear but the UX is confusing — the dropdown offers options that can never produce results for the current selection. Dynamically filtering based on `Object.keys(masaData)` after age resolution would eliminate dead options.

## Residual "15 tahun" reference in comparison table type description

The comparison table "Tipe Premi" row reads:

```
Plan A: YRT (naik per tahun)
Plan B: Level (tetap 15 tahun)
Plan C: Limited Pay (tetap 5 tahun)
```

The Plan B entry describes the *type* of premium as "level, fixed for 15 years" while Plan C says "limited pay, fixed for 5 years." These appear to highlight the longest term for B and the shortest for C as representative examples. With all other Plan B references on the page now standardized to 5-year pricing, a reader seeing "tetap 15 tahun" in this row might wonder why the characterization doesn't match the example calculations directly below it (which all show 5-year totals). This is a cosmetic inconsistency, not a data accuracy error — the "Masa Bayar" row immediately below correctly lists "5/10/15 tahun" for both plans.
